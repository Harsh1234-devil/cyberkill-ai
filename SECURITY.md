# Security Policy

## Responsible Disclosure
Cyberkill.ai is designed strictly for authorized penetration testing, security auditing, and defensive research. 

If you discover a security vulnerability within Cyberkill.ai itself, please report it via private email to:
**Harsh Vardhan** — `security@cyberkill.ai`

Please do not open public issues for zero-day disclosures.

## Ethical Usage Disclaimer
Users must ensure they possess explicit, legally binding written authorization before conducting assessments against any network, domain, or host.
